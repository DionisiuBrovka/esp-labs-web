# Дизайн-описание mgkct.minskedu.gov.by

Сайт: [mgkct.minskedu.gov.by](https://mgkct.minskedu.gov.by/) — Минский государственный колледж цифровых технологий.
Собрано из реальных computed-стилей и скриншота страницы (скриншот: `mgkct-full.png` в корне репозитория).

## 1. Общая стилистика

Классический государственный портал на **Bootstrap 5**: строгий, «бумажный», информативный.
Синяя гамма (от светлого льда до тёмного индиго), белые карточки без теней, плоские кнопки, минимум движения.
Сетка: `container` до **1320px**, брейкпоинты Bootstrap (576 / 768 / 992 / 1200 / 1400).

## 2. Палитра

| Токен | Цвет | Где |
|---|---|---|
| Primary | `#0D6EFD` | навбар, кнопки, ссылки, активные вкладки |
| Dark primary | `#0056A7` | шапка, футер, акцентные панели («Поздравляем!», «Центр компетенций») |
| Фон страницы | `#F1F8FF` | очень светло-голубой, «ледяной» |
| Текст | `#212529` | основной (Bootstrap gray-900) |
| Muted | `rgba(33,37,41,.75)` | даты, второстепенное |
| Alert-фон | `#CFE2FF`, рамка `#9EC5FE`, текст `#052C65` | информационные полосы под hero |
| Рамки карточек | `#C8C8C8` / `rgba(0,0,0,.176)` | 1px, без тени |

## 3. Типографика

- **Body**: системный стек `system-ui, -apple-system, "Segoe UI", Roboto…`, 16px/24px, weight 400.
- **Шапка колледжа**: `Rubik Bold` 36px, белый, над меткой «Учреждение образования».
- **Заголовки секций**: 26px, weight **500**, `#212529`, с иконкой слева и «шестерёнкой» справа (flex between).
- **Заголовки новостей**: ~18px, weight **600**.
- **Служебный шрифт**: `BadScript` для поздравительного стиха (декоративный акцент).
- Иконки — **Font Awesome 5/7** (в навигации, футере, заголовках секций).

## 4. Компоненты

- **Шапка**: тёмно-синяя `#0056A7`, слева цветной 3D-логотип-куб (красные/зелёные/голубые грани), справа переключатель BE/RU/EN пилюлями.
- **Навбар**: сплошной `#0D6EFD`, ссылки белые 15px **700**, активная — full white, неактивные — `rgba(255,255,255,.75)`; втянут поиск + синяя кнопка.
- **Hero**: полноширинный **Swiper-слайдер** фотобаннеров, подпись белым italic-bold в левом низу («Мы открываем новые возможности!»).
- **Info-полосы**: светлый `#CFE2FF`, 1px-рамка `#9EC5FE`, радиус 6px, текст по центру, стрелка → справа.
- **Секции**: белые карточки, радиус **6px**, рамка 1px `#C8C8C8`, **тени нет**, padding 16px; внутри — двухколоночные блоки «Расписание / Анонсы».
- **Кнопки**: плоские, `#0D6EFD`, белый текст 400, радиус 4–6px, padding 4–6px 8–12px, без тени и градиентов; иконка внутри («На неделю», «Подробнее»).
- **Карточки новостей**: сетка **4 колонки**, фото 3:2 (object-fit), заголовок semibold, дата muted, маленькая CTA «Подробнее» справа внизу.
- **Вкладки** (Новости колледжа / комитета / Министерства): активная — белая «наклейка», неактивные — синие ссылки.
- **Футер**: `#0056A7`, белым: полоса партнёрских логотипов, контакты с иконками, соцкнопки, поиск, «Карта сайта»; inset-тень сверху.
- **Доступность**: кнопки A-/A/A+/A++ в шапке (установка размера шрифта) — обязательный элемент госсайта.

## 5. Движение и интерактив

Только слайдеры (Swiper: баннеры, новости, анонсы). Никаких hover-анимаций, парраллакса, теней при наведении —
статичный, «печатный» характер.

## 6. Как воссоздать в токенах

```css
:root {
  --primary: #0d6efd;          /* кнопки, ссылки, навбар */
  --primary-dark: #0056a7;     /* шапка, футер, акцентные панели */
  --bg: #f1f8ff;               /* фон страницы */
  --ink: #212529;              /* текст */
  --muted: rgba(33, 37, 41, .75);
  --info-bg: #cfe2ff;  --info-border: #9ec5fe;  --info-ink: #052c65;
  --line: #c8c8c8;             /* рамки карточек */
  --radius-card: 6px;  --radius-btn: 4px;
  --container: 1320px;
  --font-body: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
  --font-display: "Rubik", sans-serif;
}
```

Правила: карточки белые, рамка 1px, **без теней**; кнопки плоские primary;
заголовки секций 26px/500 с иконкой; сетка карточек 4 колонки с фото 3:2; единственное движение — слайдер.
